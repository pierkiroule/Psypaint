# PsyKaleido

PsyKaleido est une expérience projective de ressourcement. La personne choisit jusqu’à trois symboles ouverts, puis leur grammaire visuelle se mêle en une matière organique, contemplative et interactive — sans interprétation automatique.

## Principes

- palette de 12 symboles configurée dans `src/data/archetypes.js` ;
- `ArchetypeMixer` fusionnant palette, mouvement, ramifications, orbitalité, symétrie et réponse audio ;
- un seul shader plein écran et un seul draw call pour une composition hybride ;
- vie autonome lente, audio-réactivité lissée et interactions tap, drag et hold ;
- interface de contemplation minimale et sortie toujours disponible ;
- aucune analyse, aucun score et aucune signification imposée aux symboles.

## Développement

